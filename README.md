# OmniPulse (native)

Releases of the native OmniPulse (0.3 on): one process, lighter and faster than the web app, with
Seamless Mix. No source here.

- **Install:** download `OmniPulse_<version>_x64-setup.exe` from the latest release.
- **From the web app:** OmniPulse 0.2.26 and later offers the switch by itself (Switch to the Native App).
  It installs in the web app's place and keeps your settings, library and playlists.
- **Updates:** the native app checks this repo a little after it starts and offers each new version.

Every installer is signed with OmniPulse's key, and the app checks that signature before installing an
update.
